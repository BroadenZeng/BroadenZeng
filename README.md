**嘉应学院 · 数学教学与教学工具探索**

我是一名数学教师，关注学生如何理解数学，也关注技术如何为学习提供恰当的支持。

我尝试从概念的引入、问题的设计和学生的思考过程出发，探索更直观、更有参与感的教学方式；同时结合交互式可视化、AI 教学智能体与自动化工具，改进课堂教学和学习体验。
