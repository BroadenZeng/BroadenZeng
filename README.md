# 曾展宽

**嘉应学院 · 数学教学与教学工具探索**

我是一名数学教师，关注学生如何理解数学，也探索如何用技术支持课堂教学与自主学习。

我拥有计算数学理学博士学位，目前在嘉应学院讲授《高等数学》《线性代数》和《解析几何》。

## 教学项目

### 高等数学交互课件

从课堂问题出发，将动态图像、逐步推导和课堂手写融入教学，帮助学生观察、思考和理解数学概念。目前已发布「洛必达法则」，其他章节持续建设中。

[在线体验课件](https://broadenzeng.github.io/higher-math-interactive/) · [查看项目](https://github.com/BroadenZeng/higher-math-interactive)

### 线代智感

由我主持的团队基于智雅平台开发，面向线性代数学习，探索如何识别学生的理解困难、提供分层提示并支持自主学习。

[体验线代智感](https://app-lc5iy18w0q0c.cxiagents.com/) · [查看项目与说明书](https://github.com/BroadenZeng/linear-algebra-learning-agent)

## 关注方向

- **数学教学设计**：概念引入、问题驱动与学生思维过程。
- **交互式数学工具**：用动态图像和可操作的演示支持数学学习。
- **AI 教学智能体**：探索识别学生的理解困难，并提供分层提示与自主学习支持。
- **教学工作流与自动化**：改进备课、练习设计和教学评价。
